# JymLight

Приложение для ведения тренировок: программы (циклы), тренировки, упражнения и подходы. Локальная база данных (Room), секундомер в уведомлении, интервальный таймер, бэкап и восстановление.

## FAQ

### Часы не вибрируют каждую минуту таймера (чекбокс «уведомление»)

Часы Xiaomi/Amazfit, подключённые через **Zepp Life**, не получают уведомления,
если приложение не отмечено в списке передаваемых приложений.
Проверьте настройки:

1. Откройте **Zepp Life** → вкладка **«Профиль»** (правый нижний угол).
2. **«Мои устройства»** → выберите ваши часы/браслет.
3. **«Уведомления приложений»** — разрешите Zepp Life доступ к уведомлениям
   телефона, если спросит.
4. Включите тумблер **«Уведомления приложений»**.
5. Нажмите **«Управление приложениями»** (внизу экрана) и **включите jymlight**
   в списке приложений.

Дополнительно:

- Убедитесь, что на телефоне разрешены уведомления для jymlight
  (Настройки → Приложения → jymlight → Уведомления, оба канала включены).
- Если телефон в беззвучном режиме или для канала «Таймер на часах» выключен
  звук — часть прошивок часов не передаёт «немые» уведомления.
- Некоторые прошивки часов схлопывают частые повторяющиеся уведомления одного
  приложения — если вибрация перестаёт приходить на длинной тренировке,
  это ограничение прошивки часов.
- Для новых устройств Xiaomi (Mi Fitness вместо Zepp Life) путь аналогичный:
  Mi Fitness → Устройство → Уведомления → в списке приложений включить jymlight.
